# Day 1 - Python & Django Training

## Project Overview
This repository contains Python exercises and a Student Management System completed on Day 1 of training.

## Files
- `task_1_basics.py` - Python basics: input handling, calculator, temperature conversion, rectangle area, salary increment
- `task_2_conditions_loops.py` - Conditional statements and loops: even/odd checks, prime numbers, multiplication tables, etc.
- `task_3_strings.py` - String operations: reverse, palindrome check, vowel/consonant count, character frequency, etc.
- `task_4_collections.py` - Lists and dictionaries: max/min, duplicates, frequency counting, marks analysis
- `task_5_student_manager.py` - Full student management system with JSON persistence


## Requirements
- Python 3.x (standard library only)

## How to Run

### Task 1 - Basics
```bash
python task_1_basics.py
```

### Task 2 - Conditions & Loops
```bash
python task_2_conditions_loops.py
```

### Task 3 - Strings
```bash
python task_3_strings.py
```

### Task 4 - Collections
```bash
python task_4_collections.py
```

### Task 5 - Student Management System
```bash
python task_5_student_manager.py
```
The program loads existing data from `students.json` if available and saves data on exit.

## Notes
- All tasks include input validation and error handling
- Student Management System uses a menu-driven interface with 9 options
